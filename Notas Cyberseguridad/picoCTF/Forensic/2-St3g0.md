# St3g0

# Descripción del reto:

Download this image and find the flag.

# Solución:

mkdir reto_st3g0 && cd reto_st3g0

wget [https://artifacts.picoctf.net/c/215/pico.flag.png](https://artifacts.picoctf.net/c/215/pico.flag.png)

zsteg pico.flag.png | grep "picoCTF{"

'picoCTF{7h3r3_15_n0_5p00n_96ae0ac1}'

# Notas adicionales:

- El nombre del reto hace una alusión directa a la esteganografía, específicamente a la técnica LSB (Least Significant Bit).
    
- En imágenes sin pérdida de calidad (como los formatos PNG o BMP), es posible alterar el último bit de los valores de color de cada píxel para ocultar datos. Dado que la variación de color es mínima (1/256), el ojo humano no percibe la diferencia, pero matemáticamente la información está ahí.
    
- Se utilizó la herramienta `zsteg`, la cual está diseñada específicamente para detectar datos esteganográficos ocultos en imágenes PNG y BMP.
    
- La herramienta iteró por los diferentes canales y métodos de codificación, encontrando exitosamente la bandera en el payload oculto dentro del canal `b1,rgb,lsb,xy`.
