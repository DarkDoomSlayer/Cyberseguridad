# 13

# Descripción del reto:

Cryptography can be easy, do you know what ROT13 is? `cvpbPGS{abg_gbb_onq_bs_n_ceboyrz}`

# Solución:

El reto nos proporciona una cadena de texto ofuscada y menciona explícitamente el algoritmo de cifrado a utilizar: ROT13.

Para resolverlo rápidamente desde la terminal de Linux, se puede utilizar el comando `tr` (translate) para mapear y desplazar los caracteres del alfabeto 13 posiciones, tanto para minúsculas como para mayúsculas.

Comando ejecutado:

Bash

```
echo "cvpbPGS{abg_gbb_onq_bs_n_ceboyrz}" | tr 'a-zA-Z' 'n-za-mN-ZA-M'
```

# Notas adicionales:

- ROT13 es un caso específico del cifrado César, un tipo de cifrado por sustitución.
    
- Se caracteriza por tener la propiedad de ser su propia función inversa; es decir, aplicar ROT13 al texto cifrado devuelve el texto plano original, ya que el alfabeto inglés tiene 26 letras (13 + 13 = 26).
    
- Las llaves `{}` y los guiones bajos `_` no se ven afectados por el cifrado porque no pertenecen al rango del alfabeto definido en el comando `tr`.
